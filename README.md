# zeeficloth
The goal of this project was to understand how HTML provides the foundation of a webpage and how CSS enhances its design. It represents my first step into the world of web programming and front-end development.

## Administrator setup

Create or repair an administrator account:

```powershell
python create_admin.py admin@example.com --password "A strong password with 8+ characters"
```

You can also set `ADMIN_EMAIL` and `ADMIN_PASSWORD` in `.env` before starting the server.

## Included features

The project includes database-backed users, products, categories, product images, sizes, colors,
inventory, carts, wishlists, orders, delivered-order reviews, payments, shipping addresses,
coupons, contact messages, settings, banners, customer management, reports, and role-based admin APIs.
